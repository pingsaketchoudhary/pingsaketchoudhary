## 2. Aesthetic & Visual Design System

### Tone & Anti-Patterns

| Category | Recommended Standard | DO NOT USE (Anti-Pattern) |
| :--- | :--- | :--- |
| **Color Scheme** | Obsidian Black (`#0B0F19`), Cobalt Blue (`#3B82F6`), Cyan (`#00F3FF`) | Cliché "Matrix Green", neon red text on black |
| **Graphics & Badges** | Clean SVG shields, minimal logos, subtle glowing borders | Fake "TOP SECRET LEVEL 5" stamps, Anonymous masks, skull icons |

## 4. Recruiter & Engineering Impact Matrix

To maximize recruiter conversion and technical credibility, every public asset must satisfy the following checklist:

1. **Language Signal Clear:** Immediately convey fluency in **Go**, **Rust**, **TypeScript**, and **Python**.
2. **Production Code Availability:** Ensure repositories contain complete build scripts (`Cargo.toml`, `go.mod`, `Makefile`, `Dockerfile`), test suites, and clean documentation.
3. **No Fluff:** Eliminate toy tutorials, incomplete forks, and unmaintained single-file scripts from pinned sections.
4. **Architectural Transparency:** Feature visual flowcharts and system diagrams in primary README files.
5. **Security Assurance:** Maintain a clear `SECURITY.md` contact vector across all major repositories.
